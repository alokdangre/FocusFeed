    Scoring rubric

    The reference rules used to judge every prediction.

    Purpose
    The video's primary format: tutorial, practice, news, commentary, entertainment, music, other, or unclear.
    Relevance
    Directly useful teaches or practices the goal; supporting assists it; unrelated does neither.
    Unwanted
    Yes only when metadata positively matches a topic the user explicitly rejected.
    Evidence
    Insufficient when metadata cannot establish subject or purpose; uncertain fields should then be unclear.
    Feed policy
    Insufficient stays visible. Explicit unwanted hides. Focus mode also hides sufficiently evidenced unrelated content.

    Visible test set

    Every input, expected label, decision, rationale, and difficulty tag for the selected split.
